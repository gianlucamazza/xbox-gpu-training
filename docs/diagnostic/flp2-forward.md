# FLP2 reconstructed forward (Fase 2)

GPU-track reconstruction of the FloppyLM **scalar** decode + a tiny decoder-block forward. Reference: FloppyLM `codec.py` / `pack.py` in FloppyLM (`gianlucamazza/floppylm`, owner, ADR 0012). **This repository does not modify xllama.** DirectML is not the trainer.

## What is specified (implemented)

| Op | Contract |
| --- | --- |
| **Scalar decode** | `W[row, col] = (symbol - half) * scale[row]`, `half = (levels-1)/2` |
| ternary | `levels=3` → codes `{0,1,2}` → `{-1, 0, +1} * scale` |
| 2-bit | `levels=4` → midrise `{±0.5, ±1.5} * scale` |
| 4-bit | `levels=16` → midrise `{±0.5 … ±7.5} * scale` |
| **Scale** | `row16` — one finite non-negative scale per row (fixture stores fp32 values) |
| **RMSNorm** | `y = x / sqrt(mean(x^2) + eps) * gamma`, `eps = 1e-6`, `1/sqrt` (not hardware `rsqrt`) |
| **RoPE** | even/odd pairing, `inv[p] = theta^(-(2p / head_dim))`, `theta = 10000` |
| **Tiny forward** | 1 layer, tied embedding, causal attention, **relu2** MLP (`max(h,0)^2`) |

HLSL: [`src/hlsl/rmsnorm.hlsl`](../../src/hlsl/rmsnorm.hlsl), [`rope.hlsl`](../../src/hlsl/rope.hlsl), [`flp2_decode.hlsl`](../../src/hlsl/flp2_decode.hlsl), [`flp2_forward.hlsl`](../../src/hlsl/flp2_forward.hlsl).

CPU reference + fixture loader: [`src/cpp/cpu_flp2.cpp`](../../src/cpp/cpu_flp2.cpp), [`src/cpp/fixture_loader.cpp`](../../src/cpp/fixture_loader.cpp).

Tiny fixture: [`benchmarks/fixtures/tiny_flp2.json`](../../benchmarks/fixtures/tiny_flp2.json) (`schema`: `xbox-gpu-training.fixture.flp2.v1`, name `tiny_flp2`). Regenerated by `python3 benchmarks/gen_tiny_flp2.py`.

## Chosen TBD tolerance

Forward / decode / RMSNorm / RoPE vs the CPU reference (same numbers as FloppyLM ADR 0004 **forward** gate):

| Gate | max-abs | max-rel |
| --- | --- | --- |
| Fase 2 FLP2 fixture | `1e-5` | `1e-4` |

Relative error is `|actual - ref| / max(|ref|, 1e-8)`.

## What is **not** reconstructed

The on-disk **FLP2 envelope** (`"FLP2"` magic, canonical header JSON, shared section, per-tensor rANS symbol stream) is **not** implemented here. That byte layout is owned by FloppyLM (`pack.py`, `rans.py`). Guessing rANS tags or header keys would be a false codec claim.

Fase 2 fixtures carry **already-unpacked symbols + row16 scales**. A `research` issue tracks envelope byte-parity against FloppyLM `pack.py` / `rans.py`.

Also not in this phase: GELU / SwiGLU / QK-norm / `row8log` / `tensor16`. AdamW / STE / ternary FakeQuant are Fase 3 ([ste-adamw.md](ste-adamw.md), [adr/0002-ste-qat-mapping.md](../adr/0002-ste-qat-mapping.md)). Full QAT + WSD + host 2/4-bit FakeQuant (same midrise lattices) is Fase 5 ([qat-wsd.md](qat-wsd.md)).

## Commands

```bat
.\build\Release\xbox_gpu_host.exe --forward-fixture fixtures\tiny_flp2.json
.\build\Release\xbox_gpu_host.exe --forward-fixture benchmarks\fixtures\tiny_flp2.json
```

Linux / no D3D12:

```bash
./build/xbox_gpu_host --forward-fixture benchmarks/fixtures/tiny_flp2.json
# CPU fixture match, then BLOCKED: no D3D12 device — dispatch log not invented.
```

Honest first lines:

- `STATUS: flp2 cpu-ref ok` (and then `BLOCKED: no D3D12 device`) — CPU fixture matched; no GPU dispatch.
- `STATUS: flp2 forward dispatched` — Windows D3D12 ran decode / RMSNorm / RoPE / forward vs CPU. WARP is software, not Series S\|X.
- `FAILED: …` — load, CPU mismatch, or a device existed and GPU parity failed.

No tok/s. No console numbers.
